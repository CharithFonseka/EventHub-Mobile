## EventHub Mobile

A cross-platform event booking mobile application built with React Native (Expo) and Firebase.

> ⚙️ **Setup instructions coming in Stage 12 (final README commit).**  
> This is a placeholder that will be replaced with full documentation including architecture overview, screenshots, and setup guide.

### Tech Stack
- React Native + Expo (TypeScript)
- Firebase (Auth, Firestore, Storage)
- React Navigation (Bottom Tabs + Native Stack)
- AsyncStorage for local persistence
- expo-notifications for local notifications
